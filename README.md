# ⚡ PixiFX Web Flasher (ESP32-S3)

Браузерный инструмент для онлайн-прошивки и первоначальной настройки Wi-Fi подключения контроллеров адресной светодиодной ленты **PixiFX** на базе **ESP32-S3** (ESP32-S3 Zero).

Интерфейс работает полностью на стороне клиента прямо в веб-браузере через **Web Serial API** и протокол **Improv Wi-Fi Serial**, не требуя установки сторонних утилит (esptool, Arduino IDE, драйверов CP2102 или CH340).

---

## ✨ Ключевые возможности

- 🚀 **Полная прошивка в один клик через Web Serial**:
  - Автоматическая синхронизация с ROM-загрузчиком ESP32-S3 через нативный USB-C CDC порт.
  - Запись всех 4 необходимых областей Flash-памяти:
    - `0x0000` — Загрузчик второго уровня (`bootloader.bin`).
    - `0x8000` — Таблица разделов PixiFX (`partitions.bin`).
    - `0x10000` — Бинарный образ прошивки (`firmware.bin`).
    - `0x210000` — Образ файловой системы LittleFS с веб-интерфейсом (`littlefs.bin`).
  - Программный и аппаратный импульс сброса (DTR/RTS) для автоматического старта контроллера после завершения записи.

- 📡 **Настройка Wi-Fi через Improv Serial**:
  - **Сканирование сетей**: отправка RPC-команды на контроллер и получение реального списка окружающих сетей с уровнем сигнала (RSSI) и шифрованием.
  - **Безопасная передача реквизитов**: передача имени сети (SSID) и пароля в память контроллера по Serial-интерфейсу.
  - **Мгновенный переход в Web UI**: получение назначенного IP-адреса устройства в локальной сети и переход в панель управления лентой в один клик.

- 🎛️ **Два удобных режима работы**:
  - **«Установка»** — полный 4-шаговый мастер: *Подключение $\to$ Прошивка $\to$ Настройка Wi-Fi $\to$ Готово*.
  - **«Wi-Fi»** — экспресс-настройка или смена параметров Wi-Fi для уже прошитого контроллера без перезаписи Flash-памяти.

---

## 🌐 Поддерживаемые браузеры

Для работы с USB COM-портом требуется поддержка **Web Serial API**:
- ✅ **Google Chrome** (версия 89+)
- ✅ **Microsoft Edge** (версия 89+)
- ✅ **Opera** (версия 75+)
- ⚠️ *Mozilla Firefox и Safari на данный момент не поддерживают Web Serial API.*

## 📁 Структура каталога

```text
web_page/
├── bin/
│   ├── bootloader.bin     # Загрузчик второго уровня ESP-IDF (0x0000)
│   ├── partitions.bin     # Таблица разделов PixiFX (0x8000)
│   ├── firmware.bin       # Скомпилированная прошивка PixiFX (0x10000)
│   └── littlefs.bin       # Образ Web UI LittleFS (0x210000)
├── lib/
│   └── esptool-js.js      # Локальный ES-модуль загрузчика Espressif
├── app.js                 # Логика Web Serial, esptool и Improv RPC
├── style.css              # Неоновые стили и адаптивная верстка
├── index.html             # Главная страница Web Flasher
├── favicon.svg            # Векторная неоновая иконка PixiFX
└── README.md              # Документация инструмента
```

## 🛠️ Локальный запуск для разработки

Из-за политик безопасности CORS запуск `index.html` напрямую через `file:///` блокирует работу ES-модулей. Используйте любой локальный веб-сервер:

### VS Code Live Server
Нажмите правой кнопкой на `web_page/index.html` $\to$ **Open with Live Server**.

### Python HTTP Server
```bash
cd web_page
python -m http.server 5500
```
После чего откройте `http://127.0.0.1:5500` в браузере.
