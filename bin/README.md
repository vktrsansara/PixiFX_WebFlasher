# Бинарные файлы прошивки PixiFX (ESP32-S3)

Поместите сюда скомпилированные бинарные файлы для веб-прошивальщика:

1. `firmware.bin` — образ прошивки приложения (Factory App). Записывается по смещению `0x10000`.
   - Можно получить после сборки: `.pio/build/esp32_s3_zero/firmware.bin`
2. `littlefs.bin` — образ файловой системы LittleFS (Web UI). Записывается по смещению `0x210000`.
   - Можно получить после `pio run -t buildfs`: `.pio/build/esp32_s3_zero/littlefs.bin`
3. (Опционально) `bootloader.bin` (смещение `0x0000`) и `partitions.bin` (смещение `0x8000`), если требуется полная перезапись чипа с нуля.
