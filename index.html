Подключение контроллера ESP32-S3

Подключите ваш контроллер PixiFX (ESP32-S3 Zero) к компьютеру через кабель USB-C и нажмите кнопку подключения.

⚠️
Обратите внимание: данная версия прошивки скомпилирована и оптимизирована исключительно под аппаратную архитектуру ESP32-S3 (двухъядерный Xtensa LX7, аппаратный RMT v2). На других ревизиях (ESP8266, ESP32 Classic, ESP32-C3) работа не поддерживается.
💡
Запуск через локальный файл (file://): Браузеры блокируют загрузку модулей по протоколу file:///. Для полноценной работы откройте страницу через локальный сервер (например, VSCode Live Server, python -m http.server или после публикации на GitHub Pages).
🚫
Ваш браузер не поддерживает Web Serial API. Пожалуйста, используйте Google Chrome, Microsoft Edge или Opera для прошивки через USB.

Настройка Wi-Fi подключения

Передайте параметры вашей домашней Wi-Fi сети прямо в контроллер через Improv Serial или воспользуйтесь резервной точкой доступа.

Подключение к Wi-Fi сети (STA)

Альтернативная настройка через точку доступа (Access Point):
Если вы не хотите передавать Wi-Fi через браузер, найдите со смартфона или ПК беспроводную сеть контроллера:
Имя сети (без пароля):
PixiFXSetup_XXXXXXXX
После подключения перейдите в браузере по адресу: http://10.10.1.1 или http://pixifx.local
